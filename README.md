
## Installation

```st
Metacello new
	repository: 'github://iriyak/KIExtensionsForGt:master/src';
	baseline: 'KIExtensionsForGt';
	load
```

## Load Lepiter

After installing with Metacello, you will be able to execute

```
#BaselineOfKIExtensionsForGt asClass loadLepiter
```
